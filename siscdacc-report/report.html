Scope and safety

This was a read-only audit: no forms were submitted and no data was changed. The optional Firestore probe used masked fields (mask.fieldPaths=updatedAt) and reports only whether a path is readable and its field names. It never prints document values. Run it only against sites you own or are authorized to test.

CRITICAL Firebase / access control FIREBASE_PUBLIC_DATA

Firestore data is readable without authentication: student marks / parent portal data

An unauthenticated Firestore REST request returned HTTP 200 for `schools/main/public/parentMarks`. Only the authorization status and field names were inspected; field values were not stored or printed.

URL: https://firestore.googleapis.com/v1/projects/siscdacc/databases/(default)/documents/schools/main/public/parentMarks

Fix: Restrict Firestore Security Rules so this path requires an authenticated, authorized user. Do not rely on a client-side PIN gate. Fix: Add a CSP at the host/CDN. Start with a safe minimum such as `frame-ancestors 'none'; object-src 'none'; base-uri 'self'` and then add script-src using hashes/nonces after testing.
